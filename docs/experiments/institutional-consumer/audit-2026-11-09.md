## Validation performed

A fresh `export-rag` followed by the documented preparation command reproduced
all fourteen initial selections, exact generation prompts, admitted contexts and
coverage results. The saved export fingerprint also matches. Four text-only audit
lists differ in event ordering because logging was sorted after the original run;
their event multisets, including multiplicity, match. Relationship-aware audit
sequences match exactly. Original measurement artifacts were not rewritten.

Two added regression tests in `tests/test_institutional_consumer.py` enforce this
CLI-to-saved-run replay and assessment traceability. Every existing rubric item
has one judgment per condition; each judgment references the corresponding raw
answer and quotes an actual substring. This checks citation integrity, not the
correctness of the AI reviewer’s conclusions.

Validation: 76 tests passed across the consumer, evidence example, exports,
institutional profile/review and schema-bundle suites. The existing institutional
evidence pack passes the reference validator. These structural checks do not
measure answer quality. The unrelated prep-tool failures recorded in the project
log remain outside this task.

## Findings and next step

The retained run supplied 8/22 expected record-body pairs in A and 20/22 in B.
This is context coverage, not an accuracy score. B supplied every expected body
for five of seven questions but still failed to reliably preserve source
authorship and explicit correction chains. All fourteen requests returned answers;
seven hit the output cap. Neither successful transport nor resolvable references
establishes epistemic preservation.

The smallest justified next experiment remains a separately specified comparison
of query-relevance ordering for nonmandatory related-record edges, preserving
qualification/supersession priority, initial retrieval and budgets. Do not tune
to question IDs or overwrite this baseline. Independent human review of the
saved answers and assessments is still pending. The repeated provenance index,
missing primary-source bodies, character-versus-token budgets, single model and
small authored question set limit conclusions; no format-level causal or general
performance claim is supported.
