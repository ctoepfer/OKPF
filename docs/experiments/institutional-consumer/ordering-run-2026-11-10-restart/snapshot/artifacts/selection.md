# Selection, access, and review limits

The selection unit is an npm release-authority incident with a bounded public
response. The two cases were chosen purposively for accessible operator accounts
and a useful mechanism mismatch. There is no sampling frame, population roster,
or denominator. Incidents without accessible primary reporting, quiet successful
transitions, abandoned projects, and other package ecosystems were not sampled.

success rate; a generic bias flag would not repair these omissions.
